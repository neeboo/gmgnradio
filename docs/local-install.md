# 本机统一构建与安装

在仓库根目录执行 `make install`。

该入口先构建应用和包内的 `gmgn-taskd`，构建失败不影响当前运行版本。安装阶段统一
替换 `/Applications/gmgn radio.app` 并切换同一用户数据目录上的后台，避免新界面
继续连接旧后台而报 `unknown_method`。检查同时核对套接字对端进程编号，确认
响应确实来自本次启动的新后台。

安装会短暂中断当前应用和后台任务。只处理目标应用及指定数据目录对应的后台，
不处理其他测试后台，不删除用户数据库。安装后新版后台已就绪，但不会自动启动
应用界面；按本项目的宿主操作约定，由用户手动打开 `/Applications` 中的新应用。

`make build` 只构建，不停止或启动应用及后台。`make test-install` 使用隔离测试，
不操作 `/Applications`、真实用户数据或运行中的应用。

默认 Debug、禁用签名，供本机开发安装；这不构成签名发布或公测分发流程。
可用 `CONFIGURATION=Release` 指定构建配置。

安装器会在目标目录旁的隐藏 `.gmgn-install-*` 目录保留 `previous.backup` 旧包；
输出包含具体路径。切换失败时尽可能恢复旧包，并明确报错，不会宣称安装成功。
后台启动失败后的回滚只恢复文件，不自动启动旧应用或旧后台。

验证记录（2026-09-08）：`make build` 实际通过，`make test-install` 的 12 项
隔离测试通过；另用完整应用包及真实后台在临时目录完成切换验证，确认旧后台退出、
新后台接口可用、不同数据目录的后台不受影响、原数据和备份保留。未启动应用界面，
未操作真实用户数据库。接口检查只确认后台认识记忆接口，不等同于居民记忆恢复验收。

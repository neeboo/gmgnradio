# 居民存储与视觉接线验收

日期：2026-09-08。验证范围为本地源码、临时数据库/进程和离线连接；未启动应用、未调用真实模型、未操作用户数据库。

## 实现范围

- Rust `gmgn-taskd` 复用单写线程与 `tasks.sqlite3`，新增按空间/居民隔离的状态、事件、消息和独立消费者确认记录。支持事务提交、revision 冲突检查、幂等重放、分页与旧库结构迁移。具体协议见 `docs/plans/2026-09-08-resident-storage-contract.md`。
- Swift 客户端接入统一协议；App 的真实运输适配用 Codable 保留数字、布尔、空值及嵌套结构，不再把标量误作字典。
- 居民计划、暂停状态与近期正式事实接入持久化。恢复仅在循环/作用域变化时启动；恢复代次和当前作用域检查防止 A→B→A 切换后旧结果触发自主活动。
- 提示词覆盖生活、工作、玩耍与装饰；自身状态从当前空间、角色、活动和手持物读取，生成及摆放仍遵守正式工具授权。
- 拍照仅支持已实现的 `current_observation`。请求经过正式工具会话的取消、期限、身份与调用账本检查。PNG 通过 Codex/DSH 原生图片通道返回；App 使用 `fileRoot: nil`，不为原生回传额外留下照片文件。
- Swift 6 并发编译修正：帧请求通过协议隔离自动切换到主线程；GPU 回调先取出可传递的错误文本，再交给主线程。保留严格编译设置。

## 尚未覆盖与明确边界

- 当前新增业务写入集中在居民计划与事实。旧场景布局、许愿记录、系统收件箱和聊天记录尚未统一迁往新状态域；新事件/消息查询及确认接口已实现和测试，但没有新增通用业务消费循环。
- 居民记忆为异步、失败可见的上下文保存。进程异常退出可能丢失尚未确认的待写草稿；它不能替代需要同步提交的委托或布局存储，也不构成完整世界事件流水。
- 全局俯瞰、头部第一人称“眼睛”视角未实现，不对模型宣称可用。画面元数据中的期望世界 revision 不代表渲染器已核验该 revision。
- 实际 GPU 画面质量、模型是否看懂照片、应用重启后的用户体验仍需手动运行验收。构建和离线测试不代表这些运行项目已经通过。

# Live Cam 人物缩小：窗口宽度修复

## 原因

2026-09-06 21:50:47，已安装应用的定向日志记录 Live Cam 的视图尺寸为 `100×336`，绘制尺寸为 `120×403.2`。设计尺寸应为 `224×336`。小窗中的自动布局将宽度收缩到内容的适配宽度，`contentMinSize` / `contentMaxSize` 没有阻止这次变化。

PMX 全身取景按视图高宽比计算横向容纳距离，因此窄视图会拉远摄像机。上次把倍率改成 1.6 仅放大了结果，没有修正窗口；该补偿已撤销。

## 修改与验证

- 在生产 `LiveCamPanel` 的内容根视图固定请求宽高，聊天与提示内容在固定窗口内布局。
- 移除测试内额外添加的宽高约束。修复前，真实 AppKit 控件测试复现 `224→100` 与 `320→100` 的窗口收缩，104 项检查中失败 22 项；修复后全部 104 项通过。
- 取景测试改为使用实际 2B 模型范围、生产相机计算和生产投影函数，检查头脚及人物占比。人物投影高度占 77.3%，头脚在画面内；三档渲染精度下占比一致。
- 本轮没有启动 gmgn 宿主或操作用户桌面。真实控件测试在未显示的测试窗口中运行；运行中的已安装应用日志仅定向读取尺寸信息。

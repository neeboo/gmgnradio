# 生成物件摆放进展

日期：2026-09-06。本批接续许愿机，未启动应用宿主、访问钥匙串或安装。整包构建结果在下方单独记录。

## 本批实现

- 正式领取记录经过文件校验及真实模型准备后，按稳定身份登记到原世界物件状态；重复同步不复制物件。
- 原世界快照保存布局，独立布局版本和幂等请求避免重复提交；保存失败不发布候选状态。
- 开放 `resident.floor` 地面区域和 `resident.display_table` 独立展示台；最多四件同时摆出。
- 底中心、米制尺寸、朝向用于显示与碰撞；候选布局检查真实舱体三角面、人物、物件、入口和固定路线。
- 右下角收起式摆放入口支持预览、移动、旋转、保存、收回及一次撤销。退出编辑重新观察，不恢复旧路线。
- 领取后的物件离开托盘显示，物件库与房间使用同一实例。生成的咖啡机目前仅有外形，不能据此声称具备煮咖啡功能。

## 居民与界面共用能力

| 能力 | 正式工具 |
| --- | --- |
| 查询已拥有物件 | `read_owned_props` |
| 查询允许的支撑面 | `list_placement_surfaces` |
| 验证候选位置 | `preview_prop_placement` |
| 摆放、移动、旋转 | `apply_prop_placement` |
| 收回 | `withdraw_prop` |
| 一次撤销 | `undo_prop_placement` |

工具预检只返回验证结果，不改变世界，也不显示用户预览。用户编辑器负责视觉预览。后台居民可读取和预检；修改布局需要当前人类指令权限。停止、编辑或换世界会撤销旧轮权限。工具会话更新至 `.tools.v5`，不接受任意本地路径作为居民参数。

## 验证记录

主代理独立复跑：

- `test-resident-prop-placement.swift`：通过。覆盖预览无副作用、保存失败、布局恢复、碰撞组合、支持面及停止。
- `test-resident-prop-editor.swift`：通过。覆盖真实编辑状态、真实 App 回调、保存中 Esc、迟到结果、重复确认和输入隔离。
- `test-resident-prop-editor-loop.swift`：通过。真实居民循环临时取消后可再次响应完成事件，明确停止仍生效。
- `test-resident-prop-surfaces.swift`：225 项通过，使用真实舱体碰撞与加载器记录的咖啡机尺寸；局部三角面 788 个。
- `test-resident-world-observations.swift`：32 项通过。整包首次编译发现新增布局事件漏接观察转换；补测试复现失败，再补正式事件映射后通过。居民收到物件编号和布局版本后查询真实状态，不根据事件编造搬运行为。
- `test-resident-prop-render.swift`：通过。尺寸、旋转、唯一预览、资源身份、世界隔离和支撑面射线。
- `test-resident-prop-app-wiring.py`：5 项通过。

子代理测试回报：WorldRuntime 116 项、居民工具 18 项通过；实际渲染生命周期及双视图归属检查通过；复杂咖啡离屏 GPU 测试产生 1,335 个可见像素。以上 GPU 数值属于离屏测试，不代表应用内体验已验收。

展示台底中心 `(-2.7,-0.03,-5)`，尺寸 `(0.9,0.55,0.65)`，顶面 `y=0.52`。咖啡机真实加载尺寸约为 `(0.350695,0.420000,0.566273)` 米。已校正测试中直接使用访问器声明边界造成的毫米级差异。

审查修正包括：准备期间取消编辑仍可能落盘、临时装修误暂停许愿续办、隐藏渲染面保留旧接口。主代理已读取并复跑前两项真实接线测试；渲染规格复查通过。原定额外独立 App/UI 质量审查因子代理额度耗尽未完成，不能记为通过。

# Unity 音乐与聊天迁移样板

## 范围

用户已授权开始独立样板；保留当前默认应用、GPUI 和 SceneKit。
先验证真实音乐播放、歌词和 3D 特效与真实 Agent 聊天在一个 Unity 窗口中并行工作。
空间编辑、高斯场景、人物资产和完整设置页不属于本轮。

## 当前进展

- 本机已安装 Unity 6000.3.20f1 和 6000.6.0f1，CLI 1.0.0-beta.5。
- 使用本机已安装的 com.unity.template.urp-blank 创建 apps/unity-player；按用户要求已通过 CLI 升级并固定 6000.6.0f1，后续构建和验收均使用此版本。
- 旧 ProductHost 会启动完整 AppDelegate、SceneKit 和自主调度，不用于样板启动。
- 独立 Swift 媒体桥接复用现有音乐组件和 DSH 连接，不要求重新填写 API key。
- Unity UI 与独立媒体桥接分开实现；均未完成运行验收。

## 必须验证

- 真实声音、播放暂停、换歌、音量和播放时间；seek 目前旧音频图缺接口，需明确解决。
- 歌词按音频时钟推进，换歌与 seek 不残留上一首内容。
- 中文字体随包发布；中文输入法选词回车不发送，Shift+Enter 换行。
- 聊天发送、取消、错误提示、流式更新和滚动位置保护。
- 音乐、3D 特效与聊天并行时不卡住、不黑屏。
- 独立 Release App 验收；Editor 编译和探针均不能替代此项。

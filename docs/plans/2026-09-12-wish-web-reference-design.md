# 居民找图并交给许愿机

用户已授权补齐链路，并明确要求工具真正提供给 agent：文字提出制作需求后，居民可以自行找图，不要求用户先上传图片或提供链接。

## 最小流程

1. `search_wish_reference_images(query)` 查询 Wikimedia Commons，返回真实图片直链及来源页面；现有网页搜索也可查找其他公开图片。
2. `register_wish_reference_image(image_url, display_name)` 安全下载、解码并去除元数据，登记到当前人类回合及空间，返回 `attachment_id`。
3. 现有 `submit_wish_generation` 使用该编号。登记不生成、不扩大消费授权；一次人类回合仍最多生成一个物件。

搜索无结果或下载失败明确返回错误；不拼造图片链接。来源与许可核验状态随参考图保留，网页内容仅作资料。首版不增加新 API 密钥、不开发网页抓取器或自动版权判断。

## 安全与生命周期

- 仅公开 HTTPS 标准端口；验证 DNS 地址，并把实际连接固定到已验证地址，避免二次解析绕过；重定向逐跳检查。
- 限制超时、跳数、传输字节、像素与输出大小；拒绝 HTML/SVG 等非支持图片，输出归一化 PNG。
- 不携带用户 cookie、认证头、代理凭据；私有缓存目录。取消或空间切换后的结果不得登记，失败清理自身临时文件。
- 模型不能传入本地路径、授权编号或空间编号。消费后的授权不能通过登记另一张图续用；重复调用保持幂等。

## 工具交付和验证

新工具并入真实 `ResidentWorldToolSession`。DSH 由共享 schema 映射 `gmgn_` 名称；Codex 工具会话版本升级，避免复用未注册新工具的旧会话。

许愿机场景的工具清单不因后台/人类回合改变：后台也注册两个 schema，但登记处理器仍拒绝无主机授权的调用。这样后台先建立的缓存会话在后续人类回合中仍有完整工具清单。

默认联网路径使用固定公共 DNS HTTPS 端点解析并筛选地址，再固定实际图片连接；系统代理提供的保留段 fake-IP 不会被加入允许名单。通用有界响应读取支持搜索 JSON，图片解码校验仅在下载参考图时执行。

分层验收：安全下载行为；真实业务工具的搜索→登记→发现→提交；真实 DSH ACP 和服务向本地模拟模型发送工具清单、接收类型化调用并同会话返回工具结果。测试不触发真实付费生成、不访问用户后台，也不启动宿主窗口。

另用 `tools/probe-resident-wish-reference-public.swift --allow-public-network` 检查默认生产下载器的真实公开搜索与图片归一化；它只下载公开参考图，不提交生成。构建、安装、窗口视觉及付费生成分别记录，不能互相替代。

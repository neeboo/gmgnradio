# gmgn radio 360° Metal 舞台设计

日期：2026-07-29  
状态：第一版已实现

## 1. 目标

为 gmgn radio 增加一个可随时打开和关闭的原生 3D 舞台。舞台以近黑空间、霓虹粒子 DJ 和高对比文字为核心，支持自动 360°环绕、鼠标拖拽、松手惯性、音频响应和节目文字。它用于主动欣赏，不取代低干扰的桌面呼吸球。

## 2. 参考与边界

Folia Major 的核心是歌词渲染器，其中 Diorama 模式把歌词光栅化成 3D 纹理平面，让镜头沿歌词路径飞行，并用粒子着色器响应音频。gmgn radio 借鉴空间文字、镜头编排和音频粒子的表达方法，不复用其 AGPL 源码，也不把产品改成歌词播放器。

Winamp 的 MilkDrop 和 AVS 提供另一条参考：视觉由可切换的预设定义，预设读取低频、中频、高频和时间参数，并在预设之间连续混合。第一版吸收这套运行方式，但不引入 projectM、Butterchurn 或旧版 AVS 代码；Metal 继续作为原生主渲染器。

第一版保留三个清楚边界：

- 主体是 DJ 的节目舞台，歌词只是可选内容层。
- 桌面呼吸球继续保持低干扰；3D 舞台默认使用普通可关闭窗口，由用户主动切换全屏。
- 用户生成内容先通过内置样例验证运行时；照片生成服务与视觉包安装在后续接入。

Unity 保留为完整音游模式的备选运行时。只有当需求进入歌词判定、复杂关卡、物理交互和创作者关卡工具时再启用；空间歌词、镜头环绕和粒子响应继续由 Metal 第一版验证。

## 3. 体验

用户从菜单栏点击“打开 360°舞台”，出现一个约 1180 × 760 的无工具栏舞台窗口：

- 背景为近黑蓝空间，由远景星尘、中景透视网格与雾化地平线建立纵深。
- 中心是由粒子组成的 DJ 图腾：头部、肩部、耳机、唱盘圆环和能量轨道。
- 场景默认缓慢完成完整环绕，始终能看到背面和侧面结构。
- 拖拽控制水平与俯仰角；松手后保留惯性并逐渐回到缓慢自动环绕。
- 低频推动主体呼吸，中频改变环形波纹，高频点亮细颗粒。
- 舞台在三种霓虹预设间自主轮换：蓝色空间网格、青色液态回声和紫色脉冲轨道。每个预设保持 20 秒，随后用 4 秒完成混合。
- 上方显示节目标题，中部短暂显示 DJ 串词；歌词模式可以把逐句文字送入同一空间文字层。
- 右下角仅保留一个全屏／视窗图标按钮；按钮文字通过辅助功能和提示呈现，不增加常驻标签。
- 关闭窗口后呼吸球仍然存在，音乐和语音会话不受影响。

## 4. 原生架构

```text
StageWindowController
└── MetalStageView
    ├── StageRenderer
    │   ├── BackgroundPass
    │   ├── ParticlePass
    │   └── StageVisualPresetTimeline
    ├── StageCameraModel
    └── StageOverlayView

VisualAudioFeatureStore
        ↓
StageAudioFrame
        ↓
Metal uniforms / particle displacement
```

`StageCameraModel` 是与 AppKit、Metal 解耦的确定性模型，负责角度、俯仰限制、拖拽灵敏度、惯性衰减和自动环绕。`StageRenderer` 只读取相机快照与音频特征。窗口生命周期由 `StageWindowController` 管理，DJCore 无需依赖具体渲染器。

## 5. 渲染方案

第一版采用两个 Metal 绘制通道：

1. 背景通道绘制近黑空间、蓝色透视网格、青紫液态波纹、脉冲轨道、星尘和雾化地平线。
2. 粒子通道一次绘制程序生成的 DJ 图腾，使用深度缓冲和透视矩阵完成真实 3D 旋转。

`StageVisualPresetTimeline` 每 24 秒推进一次预设，并把当前与下一预设转换成三个归一化权重。权重通过统一参数同时进入背景和粒子着色器，因此颜色、形变、网格密度和粒子大小能够连续变化，不会发生硬切。

粒子顶点在初始化时用固定种子生成，确保视觉回归稳定。顶点着色器完成相机变换、低频位移、环形脉冲和点尺寸计算；片元着色器绘制带柔边的圆形光点。首版不加入昂贵的多通道历史帧反馈，先保证 60/120 帧和清晰轮廓。后续 DJ 可以用节目与曲目信息替代固定时间线来选择目标预设，渲染合同无需改变。

## 6. 文字与歌词

第一版的节目标题和 DJ 串词使用 AppKit/SwiftUI 覆盖层，保证中文字体清晰。空间歌词的数据合同提前固定：

```swift
struct StageTextCue {
    let id: String
    let text: String
    let startsAt: TimeInterval
    let endsAt: TimeInterval
    let emphasis: Float
}
```

后续把 CoreText 光栅化结果上传为 Metal 纹理，并作为 3D 平面放入场景。歌词时间轴、DJ 串词和节目提示共用这一合同。

## 7. 验收

- 菜单栏能够打开、聚焦和关闭舞台窗口。
- 自动相机在静止状态持续完成完整 360°环绕。
- 拖拽旋转方向自然，俯仰不会翻转，惯性能够衰减。
- 粒子主体具有清楚的正面、侧面和背面轮廓。
- 黑底霓虹视觉在普通亮度下具有足够对比度，文字保持清晰。
- 音频特征改变粒子位移、大小和亮度。
- 三种预设保持稳定，并在最后 4 秒平滑混合。
- 右下角按钮能够进入全屏，进入后图标切换为退出动作，返回视窗后恢复。
- 窗口关闭不影响呼吸球、音乐和 DJ 会话。
- 单元测试覆盖相机模型和场景参数；全量 macOS 测试通过。

# 生活舱镜头前进方向

用户确认：W 朝画面中心指向的方向前进，S 沿相反方向后退；俯视前进下降，仰视前进上升。A/D 维持水平左右侧移。不增加 Q/E，不引入人物附身或步行物理。保留鼠标转向、Shift 加速、双击镜头复位。

实现采用相机 yaw/pitch 的单位朝向向量，避免随俯仰改变移动速度。默认生活舱视点从 2.15 米降至 1.65 米，俯角减为 -0.16 弧度，不修改用户已有存档。已有镜头可双击复位到新的默认视点。

验证：真实相机方法测试覆盖低头、抬头、后退、偏航、侧移与单位步长；真实生活舱 GLB 检查新默认镜头无碰撞。低优先级串行构建，不操作桌面、不自动重启用户正在使用的应用。
